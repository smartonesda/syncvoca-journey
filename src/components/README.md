# Shared Components

Komponen shared disiapkan untuk kebutuhan real apps:

- `layout`: shell, page scaffold, dashboard frame, mobile PWA frame.
- `feedback`: toast, modal, empty state, loading state, error state.
- `forms`: input, select, textarea, checkbox, toggle, segmented control.
- `data-display`: data table, status badge, consent badge, audit timeline.
- `navigation`: top navigation, sidebar, bottom navigation.
- `pwa`: service worker registration dan install prompt.

Komponen final sebaiknya memakai token warna dari `globals.css`, ikon dari `lucide-react`, dan tidak memakai `alert`, `confirm`, atau `prompt`.
